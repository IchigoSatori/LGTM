# Container Security Pipeline — Data Flow

## Overview

This pipeline enforces a **scan-before-run** policy for container images. No image runs locally unless it passes a Trivy vulnerability scan. All scan results are persisted as JSON and aggregated into a human-readable dashboard.

---

## Components

| Component | File | Role |
|---|---|---|
| **Quarantine Script** | `scripts/quarantine-run.sh` | Pull → Scan → Gate → Run or Block |
| **Dashboard Script** | `scripts/dashboard.sh` | Aggregate JSON reports → Markdown dashboard |
| **Audit Store** | `~/.quarantine_audit/*.json` | Persistent scan report storage |
| **Dashboard Output** | `AUDIT_DASHBOARD.md` | Human-readable audit summary |

---

## Key Data Artifacts

### `~/.quarantine_audit/<image>-report.json`
Produced by Trivy after each scan. Fields consumed by `dashboard.sh`:

| jq Path | Used For |
|---|---|
| `.Metadata.RepoTags[0]` | Image name |
| `.CreatedAt` | Scan date |
| `.Results[].Vulnerabilities[].Severity` | HIGH / CRITICAL counts |

### `AUDIT_DASHBOARD.md`
Markdown table generated by `dashboard.sh`. Columns:

`Image Name | Scan Date | HIGH | CRITICAL | Status`

---

## Decision Gate

The central control point is the **Trivy exit code** captured in `quarantine-run.sh`:

```
SCAN_EXIT_CODE=$?

if [ $SCAN_EXIT_CODE -ne 0 ]; then
    # QUARANTINE: block + purge image
else
    # PROMOTE: run container
fi
```

| Exit Code | Meaning | Action |
|---|---|---|
| `0` | No HIGH/CRITICAL vulns | `docker run` — image promoted to runtime |
| `1` | Vulnerabilities found | `docker rmi -f` — image purged, execution blocked |

## End-to-End Flow Summary

```
[User] ──► quarantine-run.sh
              │
              ├──► docker pull          (fetch image)
              ├──► trivy scan           (assess risk)
              │       └──► .json report (persist audit trail)
              │
              ├── FAIL ──► docker rmi   (quarantine)
              └── PASS ──► docker run   (promote to runtime)

[User] ──► dashboard.sh
              └──► .json reports ──► AUDIT_DASHBOARD.md
```
